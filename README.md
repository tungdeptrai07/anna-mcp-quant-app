# AnnaQuant MCP — Multi-Agent DeFi & Whale Intelligence App for Anna AI OS

**Hackathon:** Anna AI App Builder Program ($6,000 Prize Pool)  
**Protocol:** Model Context Protocol (MCP JSON-RPC 2.0)

## Overview
**AnnaQuant MCP** packages 3 high-utility on-chain intelligence tools (`scan_whale_flows`, `audit_token_contract`, `simulate_rebalance`) into a turnkey Marketplace App for **Anna AI OS**, enabling human-agent teams to audit tokens, track smart-money flows, and rebalance portfolios directly in chat.
